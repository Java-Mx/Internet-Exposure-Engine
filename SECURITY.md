# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in this repository, please report it to the maintainers at: ashwinchhawaniya2@gmail.com

When reporting, include:
- A clear description of the issue and potential impact
- Steps to reproduce (proof-of-concept if possible)
- Affected versions/branches
- Any relevant logs, stack traces, or screenshots

If the issue contains sensitive information (passwords, private keys, PII), please do not post it in public issue trackers. Send it only to the contact email above.

## Response Process

- We will acknowledge receipt within 3 business days.
- We aim to provide a remediation timeline or mitigation guidance within 14 calendar days for high-severity issues, and will keep reporters informed about progress.
- Once a fix is ready, we will coordinate a responsible disclosure with the reporter and publish a security advisory or release notes.

## Supported Versions

We consider the default branch (main) to be the actively maintained version. If specific releases are published, they will be listed in the release notes and may have their own maintenance lifecycles.

## Safe Harbor

Please avoid exploiting reported vulnerabilities beyond the minimum required to demonstrate or reproduce the issue. Do not access, modify, or exfiltrate data that you do not have explicit authorization to access.

## Acknowledgements

We appreciate responsible disclosure. Reporters who help identify and responsibly disclose verified vulnerabilities may be credited in security advisories or release notes unless they request anonymity.
